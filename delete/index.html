11 November 2026

LifeHub does not create an account on a server. There is no login held for you, and no copy of your information for anyone else to delete. Everything you enter is stored in the browser on your device.

Delete it from this page

These open LifeHub and ask you to confirm. Nothing is removed until you confirm. If LifeHub is locked, unlock it and the same confirmation appears.

Delete this profile's data

Delete all data on this device

Delete this profile's data erases that profile on this device, including its photos and documents. Other profiles on the device stay.

Delete all data on this device clears every profile, this site's local storage, caches and on-device database. Export a backup from Settings first if you want a copy. Deletion cannot be undone.

Other ways to remove it

  • In the browser, clear site data for LifeHub.
  • If you installed LifeHub to your home screen, remove the icon and then clear the site data. Removing the icon alone can leave the saved data in the browser.

Email support@lifehubapp.app if you need these steps explained. The data cannot be erased from here, because a copy is never received.
